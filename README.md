# Python - Exercícios em Aula

Coleção de exercícios básicos de Python feitos em aula no curso de Ciências da Computação (Unicsul). Os exercícios praticam entrada e saída de dados, operações matemáticas, variáveis e funções.

## Exercícios

| Arquivo | Descrição |
|---|---|
| [Exercicio 01.py](Exercicio%2001.py) | Recebe profissão, idade, sobrenome e esporte favorito e exibe cada um na tela |
| [Calcularmedia.py](Calcularmedia.py) | Calcula a média de 4 notas |
| [CalculoRaizes.py](CalculoRaizes.py) | Calcula as raízes de uma equação do 2º grau (fórmula de Bhaskara) |
| [CalculoVelocidade.py](CalculoVelocidade.py) | Calcula a velocidade média (km/h) a partir da distância e do tempo de viagem |
| [ConversaoTemperatura.py](ConversaoTemperatura.py) | Converte graus Celsius para Fahrenheit e Kelvin |
| [CotacaoDolar.py](CotacaoDolar.py) | Converte um valor em dólares para reais, de acordo com a cotação informada |
| [Salário acrescido de comissão..py](Sal%C3%A1rio%20acrescido%20de%20comiss%C3%A3o..py) | Calcula o salário com acréscimo de 5% de comissão |
| [Valores dos lados de um retângulo.py](Valores%20dos%20lados%20de%20um%20ret%C3%A2ngulo.py) | Calcula o perímetro e a área de um retângulo |

## Como executar

Requer [Python 3](https://www.python.org/downloads/) instalado.

```bash
python CotacaoDolar.py
```

Substitua `CotacaoDolar.py` pelo nome do exercício desejado. Os programas pedem os valores pelo terminal.
